# JMkvpropedit

A batch GUI for mkvpropedit (part of [MKVToolNix](https://mkvtoolnix.download/)).

This version adds support for more MKV track flags and other new features, and the Windows download comes with Java bundled, so you don't need to install it. See the [release notes](../../releases) for details.

Created by Bruno Barbieri ([BrunoReX/jmkvpropedit](https://github.com/BrunoReX/jmkvpropedit)), updated to modern Java by [sergeloie](https://github.com/sergeloie/jmkvpropedit). BSD license, see [license.txt](license.txt).
