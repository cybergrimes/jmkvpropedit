## New

- An "Update track statistics" option on the General tab. It recalculates each track's bitrate, duration, frame count and size, which MediaInfo and media servers show. It reads each file in full, so it takes about as long as copying the file. It also removes extra details that some tools store with the statistics, such as MakeMKV's "Original source medium".
- A "Remove name" option next to each track's name.
