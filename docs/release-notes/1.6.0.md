## New

- You can now mark tracks as Hearing impaired (SDH), Visually impaired, Text descriptions, Commentary or Original language. MKVToolNix 57+ required.
- You can type a regional language code, such as pt-BR for Brazilian Portuguese or es-419 for Latin American Spanish, instead of choosing from the list.
- A "Stop after current file" button. Stopping now waits for the current file to finish, so a file is never left half edited.
- When a batch finishes, you get a summary of which files worked, which had warnings and which failed.
- A Start folder setting on the Options tab, so the file and folder pickers open in your movie library instead of your user folder.

## Fixed

- Titles and track names with quotes or apostrophes, such as Director's Cut, are now saved exactly as typed.
- Extra parameters with spaces inside quotes now work the same way the preview shows them.
- An "Edit this track" box that is ticked with nothing else set no longer causes errors on files with fewer tracks.
- Files added from a folder are now listed in name order, so episode numbering comes out right.
- Settings are saved in your user folder, so the app works when it's installed in Program Files.
